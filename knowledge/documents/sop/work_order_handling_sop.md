# 设备维修工单处理 SOP

> 文档类型：示例企业知识文档  
> 分类：sop  
> 版本：V1.0

## 1. 工单创建条件

建议在以下情况下创建维修工单：

- 设备故障导致无法生产
- 同类报警重复发生
- 点检发现影响运行的异常
- 设备存在持续异常噪音、振动或泄漏
- 维护人员要求进一步检查

## 2. 工单信息

工单至少应描述：

- 设备编码
- 异常现象
- 报警代码
- 发生时间
- 是否影响生产
- 已采取的初步措施

## 3. 优先级参考

- low：不影响当前生产，可计划处理
- medium：存在异常，需要安排处理
- high：明显影响生产效率或质量
- urgent：设备无法运行或存在重大生产影响

## 4. 关闭前确认

工单关闭前应确认：

1. 异常原因已记录。
2. 处理措施已记录。
3. 设备已完成必要验证。
4. 如需持续观察，应明确后续跟踪项。
